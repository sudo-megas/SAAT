# SAAT v1.8.2

This release changes how SAAT is built and published, not how it behaves — there are no
application changes in this release.

Every previous release was built by hand on the maintainer's Arch Linux machine. Starting
with this version, releases are built by GitHub Actions on Ubuntu 22.04, which requires
glibc 2.35 or newer to run: in practice, Ubuntu 22.04 and newer, Debian 12 and newer,
Fedora 36 and newer, Linux Mint 21 and newer, and current Arch. The previous "produced on
Arch, may not run on older distributions" caveat no longer applies.

## Download

Download `SAAT-v1.8.2-linux-x86_64.tar.gz` from this release, extract it anywhere, and run
the `SAAT` executable inside:

```sh
tar -xzf SAAT-v1.8.2-linux-x86_64.tar.gz
cd SAAT
./SAAT
```

Your data (`watches/`, `config.toml`, `backups/`) is created and read beside the
executable, so the whole folder is portable — move it to another machine or a USB stick
and the collection travels with it.
